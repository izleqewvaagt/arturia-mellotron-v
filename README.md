## Overview

Arturia Mellotron V faithfully recreates the legendary Mellotron, the tape-based keyboard instrument responsible for the orchestral textures in classic rock and progressive music.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Mellotron V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Tape Library** | Large library of Mellotron tape banks including flutes, strings, and choirs |
| **Tape Mechanics** | Wow, flutter, and tape aging models for authentic degraded tone |
| **Dual Banks** | Play two tape banks simultaneously for layered textures |
| **Expanded** | Additional tape banks beyond the original hardware library |
